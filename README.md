Student Details Management System

A simple full-stack web application that allows users to submit and store student information using a responsive frontend and a Node.js/Express backend connected to a MySQL database.

Features

Add student details including:
Name
Roll Number
Course
Year
CGPA
Submit data asynchronously using the Fetch API.
Store student records in a MySQL database.
Display server responses dynamically on the webpage.
Basic database operations for learning full-stack development.

Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: Node.js, Express.js

Database: MySQL
